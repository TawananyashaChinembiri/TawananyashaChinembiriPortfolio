SQL, in practice

A query style I actually write — click run.

risk_query.sql 
SELECT p.patient_id, p.age,
       AVG(r.risk_score) AS avg_risk
FROM   patients p
JOIN   risk_scores r ON r.patient_id = p.patient_id
WHERE  r.model_version = 'v3'
GROUP  BY p.patient_id, p.age
HAVING AVG(r.risk_score) > 0.7
ORDER  BY avg_risk DESC;
